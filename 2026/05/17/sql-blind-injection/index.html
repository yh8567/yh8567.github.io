什么是盲注

当注入获取的数据不能回显到前端页面时，我们需要用特殊方法判断和尝试，这就是盲注。

三类盲注：

类型 依赖条件 常用函数
布尔盲注 页面有输出判断标准 length, left, substr, ascii, ord
时间盲注 完全无回显 if, sleep
报错盲注 有报错容错处理 updatexml, extractvalue, floor

布尔盲注

基本思路： 爆库名长度 → 逐位猜库名 → 爆表数量 → 爆表名长度 → 逐位猜表名 → 爆列数量 → 爆列名 → 爆数据

布尔盲注常用函数

函数 用途 示例
length() 获取字符串长度 length(database())=7
left(a,b) 从左侧截取 a 的前 b 位 left(database(),1)='p'
substr(a,b,c) 从 b 位置截取 a 的 c 长度 substr(database(),2,1)='i'
mid(a,b,c) 同 substr mid(database(),1,1)='p'
ord()/ascii() 字符转 ASCII ord(left(database(),1))=112
like 模糊匹配 like 'ro%'
regexp 正则匹配 regexp '^xiaodi[a-z]'

报错盲注

适用场景： union select 无法用，但页面有报错信息显示。

updatexml() 函数

三个参数：被修改的 XML 数据、XPath 路径表达式、新值。当 XPath_string 格式错误时，MySQL 会爆出 XPath 语法错误，从而泄露信息。

extractvalue() 函数

两个参数，其余和 updatexml 相同。

updatexml() 和 extractvalue() 爆出的错误信息最多显示 32 个字符，所以需要配合 limit 0,1 逐条获取。
