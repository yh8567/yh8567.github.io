五，命令执行（172.150.23.24）

在这里，我们是通过47.76.212.174:9080 这个网站请求测试网站来进行测试，但是”输入IP地址”这里输入任何网站或者参数都是无用的

为什么？首先攻击是通过控制”请输入要查询的网站”的值来此访问站点进行测试，这里有SSRF利用这台服务器来请求地址，它们之间的网络是通讯的，可以正常请求

而”请输入ip地址”此处，这是本机网络对目标ip请求建立连接，所以想要进行攻击，就得想办法将攻击语句转移到第一处利用服务器通讯建立连接，之后再进行测试攻击。

而且还有一点，

如四示例，还有sql注入等，之前的代码注入和 SQL 注入都是直接通过 GET 方式来传递参数进行攻击的，但是这个命令执行的场景是通过 POST 方式触发的，我们无法使用使用 SSRF 漏洞通过 HTTP 协议来传递 POST 数据，这种情况下一般就得利用 gopher 协议来发起对内网应用的 POST 请求了

gopher 的基本请求格式如下：

gopher 协议是一个古老且强大的协议，从请求格式可以看出来，可以传递最底层的 TCP 数据流，因为 HTTP 协议也是属于 TCP 数据层的，所以通过 gopher 协议传递 HTTP 的 POST 请求也是可以的
